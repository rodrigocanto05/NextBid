# Relatório Individual Semanal

## Descrição das Atividades

Durante esta semana, estive focado no refinamento das interfaces e na realização de testes ao projeto, garantindo que todas as funcionalidades planeadas para apresentação estivessem corretamente implementadas e funcionais.

## Trabalho Realizado

- Finalização das wireframes de alta fidelidade das páginas:
  - Caça ao Tesouro  
  - Menu Perfil  
  - Adicionar Fundos  

- Realização de alterações de layout para melhorar a organização e usabilidade da aplicação  

- Execução de testes às funcionalidades do projeto para validação da apresentação final  

- Implementação de restrições no chat  

- Atualizações ao sistema de refresh do chat para melhorar a sincronização das mensagens  

## Conclusão

O trabalho desenvolvido nesta semana permitiu concluir componentes importantes da interface do projeto, bem como melhorar a estabilidade e funcionamento do chat, contribuindo para uma apresentação mais completa e funcional da aplicação.

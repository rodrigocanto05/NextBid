# Relatorio individual 

## Descrição das Atividades

Durante a presente semana, o foco de trabalho incidiu sobre o desenvolvimento das mid wireframes do projeto. Esta fase correspondeu à criação de versões intermédias das interfaces, com o objetivo de estruturar de forma mais rigorosa a organização dos elementos visuais, os fluxos de navegação e as funcionalidades principais da aplicação.

## Trabalho Realizado

- Desenvolvi da mid wireframe da Homepage
- Desenvolvi da mid wireframe do perfil
- Desenvolvi a mid wireframe do login 
- Criação da mid wireframe do menu licitar
- Estruturação dos fluxos de navegação entre estas páginas  
- Alinhamento com os requisitos definidos para o projeto  

## Conclusção 

Realizei este trabalho semanal consolidando a estrutura do nosso projeto, para que no futuro seja um suporte para melhorias do mesmo.

# Relatório Individual – Fase II

## Contributo Individual

No desenvolvimento da segunda fase do projeto **NextBid**, o meu contributo centrou-se principalmente na **conceção e implementação da base de dados**, na **melhoria do backend existente**, no desenvolvimento do **backoffice e dashboard**, e na **validação completa da API através de testes no Postman**.

---

## Base de Dados

Fui responsável pela criação e estruturação completa da base de dados do sistema.

### Modelação

Desenvolvi toda a modelação necessária, incluindo:

- Diagrama UML
- Casos de uso
- Estrutura lógica da base de dados

A base de dados foi desenhada para suportar todas as funcionalidades da plataforma, incluindo:

- Utilizadores  
- Leilões  
- Licitações  
- Transações  
- Notificações  
- Gamificação  

---

### Estrutura e Implementação

Implementei todos os componentes da base de dados, nomeadamente:

- Criação de tabelas  
- Definição de relações entre entidades (chaves estrangeiras)  
- Queries SQL  
- Scripts de inserção de dados (inserts)  

Foi garantida a integridade dos dados e a coerência entre todas as entidades do sistema.

---

## Backend

Trabalhei sobre a primeira versão do backend existente, focando-me na sua melhoria e expansão.

### Melhorias realizadas

- Correção de inconsistências existentes  
- Adição de funcionalidades em falta  
- Melhor organização do código  
- Validação de inputs  
- Tratamento de erros  

O backend foi ajustado para suportar corretamente toda a lógica da aplicação e garantir uma comunicação eficiente com a base de dados.

---

## Backoffice e Dashboard

Fui também responsável pelo desenvolvimento do **backoffice** e da **dashboard administrativa**, permitindo a gestão da plataforma.

### Funcionalidades implementadas

- Visualização e gestão de utilizadores  
- Gestão de categorias  
- Controlo de leilões  
- Acesso a informação geral do sistema  

A dashboard permite uma visão global do estado da aplicação, facilitando a monitorização e administração do sistema.

---

## Testes (Postman)

Realizei testes completos à API utilizando o **Postman**, criando uma coleção organizada com todos os endpoints.

### Testes realizados

- Testes de sucesso (fluxos normais)  
- Testes de erro (validações e exceções)  
- Testes de autenticação  
- Testes com diferentes tipos de utilizadores (normal e admin)  

Foram validados cenários como:

- Registo e login  
- Criação e gestão de leilões  
- Licitações  
- Transações  
- Notificações  
- Gamificação  

---

## Validação do Sistema

O trabalho desenvolvido permitiu garantir que:

- A base de dados suporta todas as funcionalidades do sistema  
- O backend processa corretamente os dados  
- A API responde de forma consistente  
- O backoffice permite gerir o sistema  
- Os endpoints estão devidamente testados
